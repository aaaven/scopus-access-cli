## 页面与域名

候选范围只含已离线复核的两个样本。精确文章 URL、DOI、基线及其哈希应写入调用工程
`restricted_metadata` 下的目标文件，再由 CLI prepare 冻结；此公开仓库不保存研究记录。

| 样本 | 获取后端 | 唯一允许的页面/子请求主机 | robots URL | 页面请求上限 |
|---|---|---|---|---:|
| D0007 | browser | `link.springer.com` | `https://link.springer.com/robots.txt` | 12 |
| D0009 | browser | `www.nature.com` | `https://www.nature.com/robots.txt` | 12 |

页面 URL 必须与已有证据逐字确认，不自动更换 `link.springer.com` 为其他域名。
重定向、弹窗和任何未列主机全部阻断，包括历史日志中的 cart、CMP、fed-libs 和 sgtm
主机。这一较窄范围是否足以取得页面是待验证事实；不足时停止，不自动追加域名。

每页上限计入 document 和所有实际放行的页面 HTTP 子请求；相同 URL 再次发送也再次
计费。两个 robots 获取各最多一次，计入同一总预算，独立 robots 上限为 2。
**总上限 26 次 HTTP 请求：24 次页面上下文请求 + 2 次 robots；零重试。**
任何未用余额不自动挪给额外页面、域名、后端或新任务。

## 执行前冻结内容

先完成源码与安装制品的完整离线套件、语法编译和仓库检查。沿用原预览并核对：

- 两条精确页面 URL、每页精确主机名单、输入基线和目标文件哈希；不新增 Scopus、
  Crossref 或 OpenAlex 请求，不读 API key，不导入登录态。
- 后端 browser、总预算 26、逐页上限 12、robots 上限 2、零重试、原授权有效期及
  历史取数代码哈希；实际运行版本另记，操作员批准的是这个具体固定范围。
- Playwright 依赖和浏览器二进制已由操作者单独准备；执行不自动下载或安装浏览器。
  新建隔离 context，路由在任何页面创建前注册，service worker、WebSocket 和弹窗
  阻断；不持久化 profile、storage state、Cookie 或请求认证头。
- 浏览器使用离线 context、拒绝代理及关闭已知后台联网的启动参数；每个放行资源由
  无 Cookie 的 Python HTTPS transport 实际发送并计费。页面/context 路由不能单独证明覆盖浏览器
  进程全部后台流量；实测须单独检查这一边界，不能把回调计费数量称为整机网络总量。

冻结预览仍不执行网络。取得批准后只使用原 run-info 执行；不在开发或自动测试中
夹带一次真实 smoke check。

## 成功、停止与恢复判据

先请求并保存当次 robots 证据。规则不可确认或禁止时停止相应页面；不把浏览器曾经
打开成功解释为访问许可。每次放行前事务持久化 ATTEMPT，响应/失败追加终结记录；
阻断请求单列，不能当作已发送或成功。遇预算耗尽、未冻结主机、redirect、401/403/429、
服务器或传输失败时按固定规则停止，不换后端、不重新建任务争取预算。

页面成功后保存原始 document 字节、rendered DOM、允许的响应元数据及各自哈希，
离线提取和导出。两个 HTML 的字段结果分别比较。完成页面恢复时离线复用；存在
ATTEMPT 后未知状态或响应后保存不完整时拒绝重新导航，保留原记录供人工核对。

验收报告单列实际发送、逐请求终结、阻断、页面状态和剩余预算。字段验收检查：
D0007 的文章 Keywords 按既定规则补空，D0009 无栏目正常留空；已有 API 摘要、作者、
关键词、参考文献与字段来源不变，候选及解析版本保留；Scopus 索引词不以外部词补齐。
不扩展作者单位，不把两页可访问或书目编号连续声明为全文完整性或批量可访问性证明。

实网验收失败也应产出受限报告；只报告这次已批准范围的事实。追加页面、域名、请求
或不同获取后端需要新的明确方案及批准。
