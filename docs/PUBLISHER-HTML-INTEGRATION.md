## 已确定的产品决定

- 继续做通用本地 Scopus CLI，复用现有工程绑定、受限目录和预算机制。不增加服务端、
  skill、身份审批系统、通知系统或多 Mac 调用。
- Scopus 主数据保留；已有非空 API 字段不覆盖。Crossref/OpenAlex 与出版社 HTML 是
  后续补全来源，各自保留原始证据、字段来源和转换版本。
- **文章页面的 Keywords 栏直接作为作者关键词 `author_keywords`。** 不要求标题必须
  写成 Author Keywords，不再围绕“是否作者提供”阻塞提取。没有该栏目正常留空，不是
  初始化失败或执行失败。Springer 的六项现在补入作者关键词。
- `dc.subject` 等主题分类及 SEO 词不混入文章关键词；外部关键词不作为 Scopus 索引词。
- 作者单位不属于本轮继续开发事项；用户明确要求先不纠结它，不扩展此轮范围。
- 页面获取是否可用，与论文是否包含某字段分开记录；不承诺每篇有全部字段。

## 推荐集成顺序

1. **先把已验证的离线解析/导入内核移到包内。** 从独立脚本抽取清晰模块，避免生产代码
   依赖 scripts 或私有 `_Budget` 的不稳定细节；保留解析版本、已有缓存及历史证据兼容。
   输入使用当前工程保存记录/HTML，不重新查询 Scopus。
2. **接入现有 enrich 工作流。** 优先复用 prepare/execute/resume/status/export 的模式，
   以 `publisher_html` 来源加可选获取后端实现，避免另造一套项目身份或余额。具体命令名
   由实施者结合现有 CLI 确认；本文的设计名不是已实现命令。
3. **静态获取和浏览器获取明确选择。** 已保存 HTML 导入完全离线；静态 HTTP 路径可复用
   原内核。Playwright 是可选依赖，不默认安装/下载浏览器，不自动以浏览器重试失败页面。
   两个来源/后端保留各自证据，不静默换地址、改查询或降级后宣称补全成功。
4. **完成下方浏览器门槛与离线验收，才准备有界实测。** 不把当前回调模型包装成已完成
   浏览器功能。新实测先冻结页面、精确域名和总/逐页请求预算，再取得当次明确批准。
5. **验收后再发布。** 完整离线套件、语法编译、安装后从源码外调用验证通过后，才构建
   新 wheel、升级本机 CLI；实网覆盖范围与离线覆盖范围分别报告，不伪称多篇成功。

## Playwright 接线必须保持的请求与恢复约束

- 一次导航会产生多个 HTTP 请求。document、脚本、CSS、fetch/XHR 等页面子请求每次
  都计入总预算及逐页预算；重复 URL 不能视为缓存命中而免记真实请求。robots 获取也
  计入独立网页预算。预算不来自 Scopus 额度，不更新其观测值。
- 使用新的隔离 context、精确主机白名单；路由在创建页面前注册。阻断 service worker、
  WebSocket、未冻结弹窗/主机和未经验证的重定向。不得依赖只处理首次 URL 的路由声称
  已覆盖重定向链。浏览器后台流量与页面上下文流量边界须明确验证。
- 每个放行请求发送前持久化 ATTEMPT，终结时追加响应/失败事件。原预算共享事务和
  进程锁；未知发送/终结状态不隐式重载，不新建任务换取预算，不自动重试。
- 完成页面保存原始 document 字节、渲染 DOM、状态、允许的响应元数据、各自哈希与
  来源；字段变换另记版本。恢复优先离线复用完成页，不能重发已保存页面。
- 不导入用户登录态，不读取 API key，不把 Cookie/凭据/正文放入控制输出或控制账本。
  robots 门禁保留；两个页面成功不等于获准批量抓取，也不是绕过宿主执行拒绝的途径。

历史浏览器日志有20次页面请求准入（document2/script12/stylesheet5/fetch1），但只在
结束时落盘、缺逐请求终结记录。它是既有实测证据，不能当成生产恢复实现；原日志的
requestfailed 包含主动阻断，不能将全部计数理解为发送失败或成功。

## 下一阶段离线验收清单

- Keywords/Author Keywords、无关键词栏目、主题分类/SEO 隔离；已有 API 关键词保留。
- 两类 HTML 缓存、不可变哈希、代码/转换版本、同源/跨源来源、旧证据兼容及合并导出。
- 模拟所有获准资源类型计费、预算耗尽、主机拒绝、重定向/弹窗/SW/WebSocket阻断。
- 崩溃点覆盖：准入前、ATTEMPT后、响应后/保存前、保存后/终结前；未知活动拒绝重发。
- 同任务双进程竞争、完成页不重发、恢复不增预算、损坏缓存拒绝、stdout/异常无内容泄露。
- 未装 Playwright 时离线导入及现有 Scopus/DOI 功能仍可用；安装后从源码外调用可用。
- 全部自动测试封锁 socket、模拟凭据/transport；真实浏览器实测另行批准并单独报告。
